# Roadmap

Planned features, in no particular order.

- [ ] Video bitrate bound to resolution — different `target_video_bitrate` / `limit_video_bitrate` per resolution
  (e.g. a lower bitrate for 720p than for 1080p)
- [ ] File renaming — name movies and shows after their title from an online metadata database API
- [ ] Simple web UI — the queue, encoding progress and the current configuration (read-only)
